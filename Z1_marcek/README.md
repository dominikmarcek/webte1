## AI deklarácia

HTML a CSS som písal prvok po prvku, atribút po atribúte; proste som si pustil techno a pracoval. Vždy som mal v hlave vizuál, ako by stránka, resp. časti stránky mali vyzerať, a teda cca konkrétne transformácie, akými to dosiahnuť. Ak som túto transformáciu spraviť nevedel, tak som sa ju najprv snažil vyhľadať, ale Google Search je v 2026 polovicu času slop, v tom prípade som sa s rovnakými vyhľadávaniami obracal na slop od [Anthropic Claude](https://claude.ai/). Na JS som použil AI, pretože nemám s JS dostatočné skúsenosti vzhľadom na časovú tiaž.
